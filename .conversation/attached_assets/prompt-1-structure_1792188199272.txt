Build "حِرز" (Heraz): an Arabic-first (RTL) awareness website for parents in Saudi Arabia about AI digital cloning of children's identity. It is a university graduation project (Princess Nourah University). Tone: calm, trustworthy, protective. Never fear-mongering.

SCOPE OF THIS STEP
Build only the skeleton: design tokens, shared layout (navbar + footer), the homepage with the real content below, and 7 more pages as styled placeholders. Do not write long content for the other pages. Do not add features I did not list (no login, forms, comments, chatbot, analytics, database, image upload). Do not wait for approval, just build.

TECH
- Simple frontend-only site (React + Vite, or plain HTML/CSS/JS, whichever is simpler). Multi-page with shared layout components.
- No data collection of any kind. No cookies, no analytics, no third-party trackers.
- <html lang="ar" dir="rtl">. Mobile-first, fully responsive. Clean, commented code so another developer can add features later.

DESIGN TOKENS (CSS variables) - every color has one meaning, use it only for that
--navy: #1D2254        trust and authority: headings, body text, navbar text, hero and footer background
--turquoise: #51EDC8   the solution / the next action: primary buttons, active states, success, highlights
--teal: #56AAAA        calm secondary: accent bars, borders, secondary icons, footer bottom strip
--bg: #EEEEEF          page background (the identity guide's light gray)
--surface: #FFFFFF     cards
Tints (percent of color over white): navy-10 #E8E9EE, navy-30 #BBBDCC, turquoise-10 #EEFDFA, turquoise-30 #CBFAEE, teal-10 #EEF6F6, teal-30 #CCE6E6
--kids: #7B61C9        TEMPORARY purple for the kids section only. Keep it in one variable so I can replace it later.
Do NOT use red, orange or yellow anywhere. Risks and warnings are shown with a navy-10 background, a navy side bar, a warning icon and a clear text label. Wrong answers use a navy outline plus an X icon plus the word "خطأ". Correct answers use a turquoise-10 background plus a check icon plus the word "صحيح". Never rely on color alone.
Contrast rules (measured): navy on white 14.9:1, navy on turquoise 10.2:1, navy on teal 5.5:1. Turquoise and teal on white are too weak for text (1.5:1 and 2.7:1). So: never put turquoise or teal text on a light background. Turquoise is only a fill with navy text/icon on top. Teal is only for bars, borders, large icons, or a strip with navy text.

TYPOGRAPHY
- Alexandria (Google Fonts, weights 300-700): all UI, body text, buttons, navigation.
- Thmanyah Serif Text Bold (local @font-face): H1/H2/H3 headings.
- Thmanyah Serif Display Black: the homepage hero headline only.
- Thmanyah Serif Text Light: short secondary lines (captions, subtitles).
- Use Western digits (1234). Body 18px on mobile and desktop, line-height 1.9, max line length about 65 characters. Headings: H1 clamp(32px, 5vw, 56px), H2 clamp(26px, 3.5vw, 38px).

COMPONENT RULES (taken from the identity guide)
- Heading style: a vertical teal bar (6px wide, rounded) on the right side of every section heading. On navy backgrounds, a thin turquoise line under the title instead.
- Primary button: pill shape (fully rounded), turquoise background, navy bold text, min height 48px, with a left-pointing arrow icon (ArrowLeft, because in RTL "next" points left). Hover: slightly darker turquoise + 2px lift. Focus: 3px navy outline with 3px turquoise offset ring.
- Secondary button: pill, transparent, 1.5px navy border, navy text. On navy backgrounds: white border and white text.
- Cards: white, radius 16px, 1px navy-10 border, soft shadow, 24-32px padding. Hover: shadow grows and the side bar turns turquoise. Whole card is clickable when it links somewhere.
- UI icons: Lucide icons (lucide-react), stroke 1.75, size 20-24, navy. Large illustration icons: the 6 identity icons from /assets/icons/, shown 64-80px inside a turquoise-10 rounded square, navy version on light backgrounds, turquoise version on navy backgrounds. Do not mix them in one row with Lucide icons of different weights.
- Icon-to-section meaning: ai-chip = افهم الاستنساخ الرقمي; photos = المخاطر المستقبلية; shield-check = قبل أن تنشر; child-protected = احمِ هوية طفلك; hands-heart = التشريعات; family = عالم حرز; اختبر وعيك uses the Lucide icon ClipboardCheck.
- Motion: 150-200ms ease for hover/focus only, no autoplay or parallax, respect prefers-reduced-motion.
- Touch targets at least 44px. Visible focus on everything. Skip-to-content link. Semantic HTML (header, nav, main, footer), alt text in Arabic on every image.
