## Behavior when the user returns from an external tab
When an external button is clicked, open the link and listen for the visibilitychange event. When the user comes back to this tab, immediately show a small modal (not a new page) with: "هل أتممت هذه الخطوة؟" and two buttons: "تمّت" and "لم أتمكن".
- "تمّت": go to the next step.
- "لم أتمكن": show a helper line and stay on the same step. For the Kollona Amn button: "لا يوجد لديك التطبيق؟ حمّله من الرابط ثم قدّم البلاغ داخله." For the SDAIA button: "الخدمة تتطلب حساب أبشر."
Store only the case number and step number in sessionStorage so progress survives switching between apps. Store nothing else. Wrap all storage access in try/catch and make sure the page works without it.
